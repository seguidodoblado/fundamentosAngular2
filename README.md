# Fundamentos de Angular 2

🇪🇸 Español · [🇬🇧 English](#fundamentals-of-angular-2)

Material de estudio en español basado en los conceptos fundamentales del curso de **Angular 2**.

Este repositorio recopila apuntes, ejemplos y prácticas guiadas para aprender Angular 2 de forma progresiva, empezando por una introducción a TypeScript y ECMAScript 6.

---

## Objetivo

El objetivo de este proyecto es ofrecer una guía de estudio clara y organizada para repasar los fundamentos necesarios para comenzar con Angular 2, incluyendo TypeScript, ECMAScript 6, declaración de variables, configuración del compilador, tipos de datos, funciones, interfaces, módulos y decoradores.

El material está pensado como apoyo para:

- estudiantes que estén comenzando con Angular 2,
- personas que preparan una formación introductoria,
- desarrolladores que quieren repasar conceptos básicos de TypeScript y ES6,
- instructores que necesitan una base estructurada en español.

# Fundamentals of Angular 2

[🇪🇸 Español](#fundamentos-de-angular-2) · 🇬🇧 English

Study material, written in Spanish, based on the core concepts of the **Angular 2** course.

This repository collects notes, examples and guided exercises to learn Angular 2 progressively, starting with an introduction to TypeScript and ECMAScript 6.

---

## Goal

The goal of this project is to offer a clear, well-organized study guide covering the fundamentals needed to get started with Angular 2, including TypeScript, ECMAScript 6, variable declaration, compiler configuration, data types, functions, interfaces, modules and decorators.

The material is intended as support for:

- students who are just starting with Angular 2,
- people preparing an introductory course,
- developers who want to refresh their knowledge of basic TypeScript and ES6,
- instructors who need a structured base (note that the notes themselves are in Spanish).
